[역할]
너는 레이싱/드라이빙 시뮬레이터를 10년 이상 만든 시니어 게임 개발자이자 차량 동역학 엔지니어야.
아래 기획을 바탕으로, 실제로 운전하는 감각을 주는 1인칭 3D 운전 시뮬레이션 게임을 만들어 줘.

[게임 컨셉]
- 배경: 미래형 AI 정의 차량(AIDV) '슈필라움(Spielraum)'을 운전하는 시뮬레이션.
- 차량의 AI가 운전자 상태와 도로 상황을 실시간으로 인식하고 돕는다.
- 목표: 시나리오별 목적지까지 안전하게, 교통법규를 지키며, 운전자 스트레스를 낮게 유지한 채 도착하기.

[기술 스택]
- 단일 index.html 파일 (HTML + CSS + JavaScript), 브라우저에서 바로 실행.
- 3D: Three.js (CDN: cdnjs.cloudflare.com), 사운드: Web Audio API (외부 음원 파일 없이 합성).
- 외부 3D 모델/텍스처 파일 없이 기본 도형과 절차적 생성으로 구성.
- 60fps 목표, 고정 타임스텝(1/120초) 물리 루프와 렌더 루프 분리.

[1. 차량 물리 — 가장 중요]
리얼함의 핵심이니 단순히 position += speed 식으로 만들지 말고 아래를 구현해 줘.
- 엔진: RPM 기반 토크 커브(아이들 800rpm, 레드라인 6500rpm), 회전수에 따른 출력 변화.
- 변속기: 자동(D/R/N/P) 기본 + 수동 모드(Q/E로 업/다운), 기어비와 최종감속비 적용, 변속 시 짧은 토크 끊김.
- 크리핑: D단에서 브레이크를 떼면 천천히 앞으로 나감.
- 타이어: 간단한 슬립 비율/슬립 각 기반 그립 모델(마찰원 개념), 노면(마른/젖은)에 따라 마찰계수 변화.
- 하중 이동: 가속 시 차체 뒤로, 제동 시 앞으로 쏠림(피치), 코너링 시 롤 — 카메라에도 미세하게 반영.
- 조향: 속도 감응형 조향(고속일수록 둔하게), 스티어링 휠 각도 → 바퀴 각도 비율 약 15:1, 손을 떼면 서서히 복원.
- 제동: 브레이크 압력 점진 적용, ABS(바퀴 잠김 방지), 공기저항과 구름저항.
- 차량 제원: 공차중량 1,800kg 전기/하이브리드 세단 기준으로 현실적인 수치 사용.

[2. 조작]
- 키보드: W/↑ 가속, S/↓ 브레이크(정지 후 길게 누르면 후진 아님 — 후진은 R단), A/D 조향, Q/E 변속, Space 사이드 브레이크, 좌/우 방향지시등(Z/C), H 경적, V 시점 전환.
- 키보드 입력도 아날로그처럼 느껴지게 페달/핸들 값을 0→1로 부드럽게 증감.
- Gamepad API로 게임패드 및 레이싱 휠(아날로그 축) 지원.

[3. 카메라와 몰입감]
- 기본 1인칭 운전석 시점: 대시보드, 스티어링 휠(입력에 맞춰 회전), A필러, 룸미러/사이드미러(별도 렌더 타깃으로 실제 후방 표시).
- 속도에 따른 미세한 FOV 증가, 노면 진동, 급제동 시 고개 쏠림.
- 3인칭 추적 시점도 V키로 전환.

[4. 월드]
- 절차적으로 생성한 도시 구역: 격자형 도로, 차선, 횡단보도, 정지선, 건물, 가로등.
- 신호등: 실제 주기(녹→황→적)로 동작, 교차로마다 독립 타이머.
- AI 차량: 차선을 따라 주행, 신호와 앞차 거리를 지킴.
- 보행자: 횡단보도에서 신호에 맞춰 건너고, 가끔 무단횡단 이벤트 발생.
- 날씨/시간: 맑음/폭우/야간 전환. 폭우 시 노면 마찰 감소, 시야 감소(안개), 와이퍼 애니메이션, 빗소리.

[5. AIDV 기술 요소 — 게임 시스템으로 구현]
(1) 투명 OLED 전면유리 HUD (3D 공간 위에 AR처럼 겹쳐 보이는 UI)
  - AR 내비: 다음 회전 지점에 도로 위로 떠 있는 청록색 화살표.
  - 위험 감지: 일정 거리 내 보행자/급정거 차량에 빨간 테두리 박스 + 거리 표시.
  - 신호등 카운트다운: 앞 신호의 남은 시간 표시, 황색 진입 시 "정지 권장/통과 가능" 판단 표시.
  - 속도, 제한속도, 기어, 에너지 잔량.
(2) 인캐빈 멀티모달 센싱 (운전 행동으로 시뮬레이션)
  - 스트레스 지수(0~100): 급가속, 급제동, 과속, 근접 충돌, 경적, 정체 시간에 따라 상승 / 부드러운 주행, AI 제안 수락 시 하강.
  - 심박수: 스트레스와 연동되어 70~130bpm 사이 변동, 화면 구석에 실시간 그래프.
  - 시선 추적 흉내: 마우스로 고개를 돌릴 수 있고, 위험 대상을 오래 안 보면 "전방 주시" 경고.
  - AI 메모리: localStorage에 이전 플레이의 습관(자주 하는 급제동 구간, 평균 속도)을 저장하고 다음 판에서 "지난번 이 교차로에서 급제동하셨어요" 같은 맞춤 안내.
(3) 상황 맞춤형 AI 에이전트
  - 스트레스가 70 이상이면 실내 조명 색이 차분한 색으로 바뀌고, AI가 음성 대신 자막으로 제안(휴식, 경로 변경, 자율주행 전환).
  - 제안은 화면 하단에 1/2/3 키로 선택하는 선택지 카드로 등장 (주행은 멈추지 않음).
(4) AI 홈 연동
  - 목적지가 집일 때, 도착 예상 시간에 맞춰 "에어컨 켜기 / 로봇청소기 끝내기 / 조명 켜기" 이벤트.
  - 우측 패널에 집 가전 상태 아이콘 표시, 운전 중 선택 결과가 도착 화면 점수에 반영.

[6. 자율주행 모드]
- 특정 구간에서 자율주행 전환 가능(F키). AI가 차선 유지, 신호 준수, 앞차 간격 유지.
- 자율주행 중에도 갑작스러운 상황(공사 구간, 무단횡단)에서 "제어권 이양 요청"이 뜨고 3초 안에 핸들/페달을 잡아야 함.

[7. 시나리오 (메인 메뉴에서 선택)]
A. 폭우가 쏟아지는 퇴근길 — 야간, 미끄러운 노면, 시야 제한, 목적지: 집(홈 연동 이벤트).
B. 스트레스가 극에 달한 출근길 — 정체, 지각 압박 타이머, 시작 스트레스 60, 자율주행 전환 판단이 핵심.
C. 가족과의 주말 장거리 여행 — 교외 도로/고속도로, 에너지 관리(충전소 들르기), 동승자 멀미 지수(급가감속 시 상승).

[8. 스탯과 판정]
- 스트레스 지수(0~100): 100이 되면 AI가 강제로 갓길 정차 → 실패.
- 차량 에너지(0~100): 가속량, 에어컨, 속도에 따라 소모, 회생제동으로 소폭 회복. 0이면 실패.
- 위반 기록: 신호위반, 과속, 정지선 침범, 방향지시등 미사용, 충돌.
- 도착 시 결과 화면: 소요 시간, 위반 목록, 평균 스트레스, 에너지 효율, AI 제안 수락률, 종합 등급(S~D).

[9. 사운드 (Web Audio로 합성)]
- RPM에 따라 음높이가 변하는 엔진/모터음, 타이어 스키드음, 방향지시등 똑딱음, 빗소리, 경고음, 경적.

[10. 코드 품질 요구사항]
- 모듈처럼 구분된 구조: Input, VehiclePhysics, World, TrafficAI, HUD, CabinSensing, AIAgent, SmartHome, Scenario, Audio, Game.
- 물리 상수는 파일 상단 CONFIG 객체에 모아서 쉽게 튜닝 가능하게.
- 주요 로직에 한국어 주석.
- 화면 좌측 상단에 디버그 토글(` 키): FPS, RPM, 슬립 비율, 바퀴별 하중.

[작업 방식]
한 번에 모든 기능을 넣으면 품질이 떨어지니 아래 단계로 나눠 진행해 줘.
이번 응답에서는 1단계만 완성된, 바로 실행 가능한 코드를 작성하고, 끝에 다음 단계에서 추가할 내용을 짧게 정리해 줘.
  1단계: 차량 물리 + 조작 + 1인칭 카메라 + 기본 도로 (운전 감각 완성)
  2단계: 도시 월드, 신호등, AI 차량, 보행자
  3단계: 투명 OLED HUD, 인캐빈 센싱, 스트레스/에너지 스탯
  4단계: AI 에이전트 선택지, 홈 연동, 자율주행 모드
  5단계: 시나리오 3종, 날씨, 사운드, 결과 화면, AI 메모리
